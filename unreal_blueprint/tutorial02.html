Not Equal 노드 사용시 허용오차

- CurRotaiton은 로테이터 타입의 변수입니다.
- Get Control Rotation과 CurRotation이 같으면 false, 같지 않으면 true를 반환 합니다.
- 허용 오차를 0.0001로 설정합니다.

만약 오차 허용 범위를 0으로 둔다면?
  • 캐릭터가 시각적으로는 이미 90도를 다 돌아서 정면을 보고 있는 것처럼 보입니다.
  • 하지만 시스템 내부의 Get Control Rotation 값은 89.99999도이고, Desired Rotation은 90.0도입니다.
  • 차이가 0이 아니기 때문에(완벽히 같지 않기 때문에), != 노드는 계속해서 True를 반환합니다.




Get Player Controller란

언리얼 엔진에서는 플레이어를 두 가지 요소로 나누어서 관리합니다.
  1. Pawn 또는 Character (육체): 화면에 보이고, 팔다리를 움직이고, 총에 맞으면 데미지를 입는 물리적인 아바타입니다.
  2. Player Controller (영혼/뇌): 키보드나 마우스, 게임패드의 입력을 받아들이고 화면(UI)을 관리하는 보이지 않는 지휘자입니다.

예) 컨트롤러 방향 가져오기
대부분 상황에서 카메라는 컨트롤러를 따라가기 때문에 같은 것처럼 느껴집니다.

Get Player Controller → Get Control Rotation

핵심: Set Control Rotation = 플레이어 시점(컨트롤러 방향)을 회전시키는 것

RInterp To

회전값(Rotation)을 “부드럽게 목표 방향으로 보간(보정)”해주는 노드입니다.

Lerp (Rotator)와 차이
  • RInterp To 속도 기반,  Lerp는 비율기반
  • RInterp To 자동 감속,  Lerp는 일정 비율
  • RInterp To 자연스러운 회전,  Lerp는 정확한 타이밍
