Texture Sampler

URP에서 텍스쳐 사용시 다음 명령에 대해 자세하게 알아 본다.

TEXTURE2D: 머티리얼의 _BaseMap 텍스처 리소스를 참조합니다.
SAMPLER: 필터링/랩핑 모드 등 샘플링 상태를 나타냅니다.

TEXTURE2D(_BaseMap);
SAMPLER(sampler_BaseMap);

1. Built-in vs URP/HDRP 스타일 비교 (핵심 차이)


항목 Built-in (CG) URP / HDRP (HLSL) 왜 바뀌었나?
선언 방식 sampler2D _MainTex; TEXTURE2D(_MainTex); SAMPLER(sampler_MainTex); DX11+ / Vulkan / Metal 호환성 + 샘플러 재사용 가능
샘플링 함수 tex2D(_MainTex, uv) SAMPLE_TEXTURE2D(_MainTex, sampler_MainTex, uv) 명시적 + 성능 최적화 가능
sampler2D 안에 텍스처 + 샘플링 상태 같이 묶임 텍스처와 샘플러 분리 여러 텍스처가 같은 샘플링 상태 공유 가능
SRP Batcher 호환 불가 가능 (매우 중요!) 배칭 성능 ↑

URP에서는 SRP Batcher 때문에 이 분리된 방식이 거의 필수입니다.


2. 각각의 의미 자세히

TEXTURE2D(_BaseMap);

  • Texture2D 타입의 변수를 선언합니다. (HLSL 기본 타입)
  • _BaseMap이라는 이름의 텍스처 리소스만 가리킵니다.
  • 텍스처 데이터(픽셀 색상들)만 가지고 있고, 어떻게 샘플링할지(필 터링, wrap 모드 등)는 모릅니다.
  • 이 한 줄만으로는 샘플링을 할 수 없습니다!

SAMPLER(sampler_BaseMap);

  • SamplerState 타입의 변수를 선언합니다.
  • 이름 규칙 : sampler + _ + 텍스처이름 (반드시 이렇게 해야 Unity가 자동 연결)
  • 이 변수는 필 터링 모드(Linear, Point), Wrap 모드(Repeat, Clamp), Aniso 레벨 등을 결정합니다.
  • Material Inspector에서 설정한 텍스처의 Filter Mode / Wrap Mode가 여기로 들어옵니다.

→ 결국 두 개가 한 쌍으로 동작해야 텍스처를 읽을 수 있어요.

3. 실제 샘플링하는 코드

half4 color = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, uv);
  • _BaseMap → 텍스처 데이터
  • sampler_BaseMap → 샘플링 방법
  • uv → 좌표

이 함수는 내부적으로 대략 이런 느낌입니다:

// 개념적 pseudo-code
half4 SAMPLE_TEXTURE2D(Texture2D tex, SamplerState samp, float2 uv)
{
    return tex.Sample(samp, uv);
}

4. 이름 규칙 꼭 지켜야 하는 이유

텍스쳐 이름 ---> sampler 이름
_BaseMap  ---> sampler_BaseMap
_MainTex ---> sampler_MainTex
_DetailAlbedo  --->  sampler_DetailAlbedo

이름이 맞으면
→ TRANSFORM_TEX 가능
→ Unity 자동 연결

이름이 안맞으면
→ Inspector에서 Tiling/Offset이 안 먹히거나
→ 아예 검은색/흰색으로 나오는 버그 발생

5. 언제 sampler를 따로 만들어 쓸가? (고급)

SamplerState sampler_linear_clamp;
SamplerState sampler_point_repeat;

// ...

half4 col1 = SAMPLE_TEXTURE2D(_BaseMap, sampler_linear_clamp, uv);
half4 col2 = SAMPLE_TEXTURE2D(_NoiseMap, sampler_point_repeat, uv * 20);

→ 같은 텍스처를 다른 샘플링 방식으로 여러 번 쓰고 싶을 때 유용합니다.

요약 한 방에

  • TEXTURE2D(_XXX) → 픽셀 데이터만 담당
  • SAMPLER(sampler_XXX) → 필터링/Wrap 방식만 담당
  • 둘이 한 쌍이 되어야 SAMPLE_TEXTURE2D로 색을 읽을 수 있음
  • 이름 규칙 엄격히 지켜야 Tiling/Offset, Inspector 연동이 정상 동작
  • URP/HDRP에서는 sampler2D 스타일 거의 안 씀 (호환성 + 배칭 문제)
