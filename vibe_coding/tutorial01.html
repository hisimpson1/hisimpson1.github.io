🚀 Gemini CLI 사용 튜토리얼

이 문서는 Gemini CLI 설치부터 API 연동까지의 과정을 정리한 가이드입니다.

1. 설치하기

터미널(또는 VS Code 터미널)에서 아래 명령어를 입력합니다.
다음 홈페이지에 가면 https://geminicli.com/    설치 명령이 있습니다.

npm install -g @google/gemini-cli

※ 설치 중 EBADENGINE 경고가 뜨면 Node.js 버전을 20.18.1 이상으로 업데이트하는 것이 좋습니다.

2. API 키 발급 (무료)

계정 권한 에러(Not eligible)를 피하기 위해 API Key 방식을 사용합니다.

  1. Google AI Studio 접속
  2. Get API key 메뉴 클릭
  3. Create API key in new project 클릭 (안 될 경우 Google Cloud 콘솔에서 프로젝트 먼저 생성)
  4. 발급된 키(AI...)를 복사

3. 인증 및 실행

터미널에서 npx를 사용해 실행하는 것이 가장 확실합니다.

npx @google/gemini
인증 선택:
화면에 선택지가 뜨면 화살표 키로 "2. Use Gemini API Key"를 선택하고 복사한 키를 붙여넣으세요.

4. 주요 명령어 및 팁

명령어 입력 예시

npx @google/gemini "현재 폴더의 파일 구조를 분석해줘"

환경 변수 설정 (export)

매번 키를 입력하기 귀찮다면 터미널에 키를 등록하세요.

export GOOGLE_API_KEY='여러분의_키_내용'

※ export는 현재 터미널 세션에 설정을 저장하는 명령어입니다.

✅ 체크포인트

  • 명령어를 못 찾겠다면 npx를 앞에 붙이세요.
  • VS Code 터미널에서도 동일하게 작동합니다.
  • 질문 시 구체적일수록 답변의 질이 좋아집니다.
